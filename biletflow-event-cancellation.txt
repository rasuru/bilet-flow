# ./docs/event-cancellation.md
# Event cancellation

`POST /api/events/{eventId}/cancel` is organizer-only and returns `204` once
cancellation and its durable notification fact commit. Repeating it does not
create another audit entry or notification campaign, including after the
original event end time. A first cancellation after the event ended is rejected.
Cancellation is terminal; publication and subsequent editing remain forbidden.

## Admission and orders

Cancellation immediately closes registration and admission. Lifecycle changes,
checkout issuance, and check-in use the same event transaction lock so issuance
or admission cannot race past a committed cancellation. Existing PDF/QR copies
cannot be recalled: online validation remains authoritative. Newly generated
ticket PDFs show cancellation and omit admission QR codes; QR downloads are
rejected.

The checkout expiry worker closes pending checkouts as `CANCELLED`, releases
reservations, and abandons their payments on its next pass (normally within five
seconds). Those operations are retried after failure. An unfulfilled late bank
capture is compensated through the existing payment saga; it does not issue
admission to the cancelled event. The bank may require reconciliation before a
void or refund is confirmed.

Completed orders and their financial history are retained. Event cancellation
**does not automatically refund completed orders or the paid-sales activation
fee**. Existing organizer-initiated full-refund eligibility and the bank outcome
remain authoritative. The cancellation email does not promise a refund.

## Notifications and calendars

The transactional outbox fans cancellation out to current attendee email
addresses (including unclaimed, checked-in, and refund-pending tickets) plus
activated organizer/staff email addresses published by IAM. Already cancelled
or refunded tickets are excluded. One notice is reserved per event and normalized
email address, even when the same person has multiple tickets or staff roles.
No account or ticket claim is required for an attendee to receive the notice.

Each notice includes an `.ics` attachment with a stable event UUID-based UID,
`STATUS:CANCELLED`, a cancellation sequence, and UTC event times. Calendar import
is a user action; BiletFlow does not have write access to the user's calendar.

Recipient fan-out and outbox acknowledgement commit together. SMTP runs outside
the database transaction. Notices survive restarts, use a two-minute recoverable
lease, and retry after 30 seconds with exponential backoff capped at one hour.
An expired worker cannot acknowledge a replacement worker's claim. Retries keep
the same Message-ID. Delivery is at least once: an SMTP acceptance followed by a
crash can produce another copy of the same notice.

`biletflow.events.cancellation-mail-enabled` defaults to `true` and controls the
SMTP worker. `cancellation-mail-delay-ms` defaults to `5000` and
`cancellation-mail-initial-delay-ms` to `10000`, under the same prefix. Disabling
the worker retains queued notices. Monitor the outbox and
`event_management_cancellation_notice` for unresolved work and SMTP failures.

Ticket-confirmation delivery skips cancelled events. A confirmation already in
flight may still arrive; the cancellation notice and online admission state
remain authoritative. Historical cancellations are not automatically mailed by
deploying this feature; only newly committed cancellation facts create campaigns.

## Verification

Run `./gradlew test integrationTest` with the project's Java toolchain and Docker.
Focused tests cover authorization, idempotent cancellation, outbox rollback,
late-payment compensation, retained completed orders, notification recipients,
SMTP retry, worker lease recovery, and calendar escaping/UTF-8 line folding.

With the development server running, a fully automated free-registration test
creates its own activated accounts and event, then verifies cancellation,
blocked sales/admission/QR downloads, retained order history, and the attendee
cancellation email captured by Mailpit:

```sh
CANCEL_EVENT=1 PRICE_KZT=0 bash scripts/e2e/biletflow-run-e2e.sh
```

Omit `PRICE_KZT=0` to also exercise the Halyk activation and ticket payments;
those payments require the sandbox browser steps. The script uses fresh fixture
events and leaves cancellation records available for inspection.

# ./scripts/e2e/biletflow-purchase-e2e.sh
#!/usr/bin/env bash
# Buy one general-admission ticket, claim it, and download its PDF and QR.
# Requires bash, curl, jq, python3, a running backend, and two activated accounts.
# The event must be published, registration/sales open, and inventory available.
# ATTENDEE_EMAIL must match the buyer account's verified email.
#
# Usage (JWTs can instead be entered at the hidden prompts):
#   export ORGANIZER_JWT='...' BUYER_JWT='...'
#   EVENT_ID='...' TICKET_TYPE_ID='...' ATTENDEE_EMAIL='buyer@example.com' \
#     bash biletflow-purchase-e2e.sh
#
# For a paid event already activated, use the default ACTIVATE=0.
# For a new paid event, ACTIVATE=1 requests sandbox activation, accepting the
# sandbox terms and simulated identity/payout verification. Pay that fee first.
# Free tickets need no activation or browser payment.
# Optional: BASE_URL, OUTPUT_DIR, TIMEOUT_SECONDS=480, PAYMENT_PORT=9090.
# Each run creates a new purchase. The script tests retries within that purchase.
# CANCEL_EVENT=1 additionally cancels the fixture event and checks admission/email.
# Otherwise leaves the ticket valid; never requests a refund.
set -euo pipefail
umask 077

fail() { printf 'FAIL: %s\n' "$*" >&2; exit 1; }
for tool in curl jq python3; do command -v "$tool" >/dev/null || fail "Install $tool"; done
BASE_URL="${BASE_URL:-http://localhost:8080}"
BASE_URL="${BASE_URL%/}"
: "${EVENT_ID:?Set EVENT_ID to a published event UUID}"
: "${TICKET_TYPE_ID:?Set TICKET_TYPE_ID to a general-admission ticket type UUID}"
: "${ATTENDEE_EMAIL:?Set ATTENDEE_EMAIL to the buyer account verified email}"
ACTIVATE="${ACTIVATE:-0}"
CANCEL_EVENT="${CANCEL_EVENT:-0}"
TIMEOUT_SECONDS="${TIMEOUT_SECONDS:-480}"
PAYMENT_PORT="${PAYMENT_PORT:-9090}"
[[ "$ACTIVATE" = 0 || "$ACTIVATE" = 1 ]] || fail 'ACTIVATE must be 0 or 1'
[[ "$CANCEL_EVENT" = 0 || "$CANCEL_EVENT" = 1 ]] || fail 'CANCEL_EVENT must be 0 or 1'
[[ "$TIMEOUT_SECONDS" =~ ^[1-9][0-9]*$ ]] || fail 'TIMEOUT_SECONDS must be positive'
[[ "$PAYMENT_PORT" =~ ^[0-9]+$ ]] || fail 'PAYMENT_PORT must be numeric'
python3 - "$EVENT_ID" "$TICKET_TYPE_ID" "$PAYMENT_PORT" <<'PY'
import sys, uuid
for value in sys.argv[1:3]: uuid.UUID(value)
assert 1024 <= int(sys.argv[3]) <= 65535, 'Use an unprivileged TCP port'
PY
if [[ -z "${BUYER_JWT:-}" ]]; then
  read -r -s -p 'Buyer JWT: ' BUYER_JWT; printf '\n'
fi
if [[ ( "$ACTIVATE" = 1 || "$CANCEL_EVENT" = 1 ) && -z "${ORGANIZER_JWT:-}" ]]; then
  read -r -s -p 'Organizer JWT: ' ORGANIZER_JWT; printf '\n'
fi
[[ -n "$BUYER_JWT" ]] || fail 'Buyer JWT is empty'

WORK="$(mktemp -d)"
SERVER_PID=''
cleanup() {
  if [[ -n "$SERVER_PID" ]]; then kill "$SERVER_PID" 2>/dev/null || true; wait "$SERVER_PID" 2>/dev/null || true; fi
  rm -rf "$WORK"
}
trap cleanup EXIT
trap 'exit 130' INT
trap 'exit 143' TERM
CHECKOUT_ID="$(python3 -c 'import uuid; print(uuid.uuid4())')"
OUTPUT_DIR="${OUTPUT_DIR:-./purchase-e2e-$CHECKOUT_ID}"
mkdir -p "$OUTPUT_DIR"
# Keep bearer credentials out of curl's command-line arguments and output files.
printf 'Authorization: Bearer %s\n' "$BUYER_JWT" > "$WORK/buyer.headers"
if [[ "$ACTIVATE" = 1 || "$CANCEL_EVENT" = 1 ]]; then
  printf 'Authorization: Bearer %s\n' "$ORGANIZER_JWT" > "$WORK/organizer.headers"
fi
unset BUYER_JWT ORGANIZER_JWT

# api ROLE METHOD PATH OUTPUT EXPECTED [BODY_FILE] [IDEMPOTENCY_KEY]
# Never retries POST automatically; checkout replay uses the same explicit key.
api() {
  local role="$1" method="$2" path="$3" target="$4" expected="$5"
  local status
  local -a args=(--silent --show-error --connect-timeout 10 --max-time 30
    --request "$method" --header "@$WORK/$role.headers" --output "$target"
    --write-out '%{http_code}')
  if [[ -n "${6:-}" ]]; then args+=(--header 'Content-Type: application/json' --data-binary "@$6"); fi
  if [[ -n "${7:-}" ]]; then args+=(--header "Idempotency-Key: $7"); fi
  status="$(curl "${args[@]}" "$BASE_URL$path")" || fail "$method $path: connection failed"
  case ",$expected," in
    *",$status,"*) ;;
    *)
      printf 'HTTP %s: %s %s\n' "$status" "$method" "$path" >&2
      # Show only ProblemDetail fields, never session/auth response payloads.
      jq -r '[.title // empty, .detail // empty] | join(": ")' "$target" 2>/dev/null >&2 || true
      fail 'Unexpected HTTP response'
      ;;
  esac
}

start_server() {
  [[ -z "$SERVER_PID" ]] || return 0
  mkdir -p "$WORK/web"
  # Match the development return URL configured in .env.local.
  cat > "$WORK/web/halyk-sandbox-checkout.html" <<'HTML'
<!doctype html>
<html lang="en">
<meta charset="utf-8">
<title>BiletFlow payment return</title>
<style>body{max-width:640px;margin:64px auto;padding:0 24px;font:18px/1.6 system-ui}</style>
<h1>Back from Halyk</h1>
<p>Check the terminal running the purchase test for the confirmed payment result.</p>
<p>If this was the activation payment, the terminal will show a new link for the ticket payment.</p>
<p>This return page alone does not confirm a successful payment. Keep the test script running while it checks the bank status.</p>
</html>
HTML
  # Bind synchronously so an occupied port cannot silently serve a different page.
  python3 - "$WORK/web" "$PAYMENT_PORT" "$WORK/ready" <<'PY' >/dev/null 2>&1 &
import functools, http.server, pathlib, sys
handler = functools.partial(http.server.SimpleHTTPRequestHandler, directory=sys.argv[1])
with http.server.ThreadingHTTPServer(('127.0.0.1', int(sys.argv[2])), handler) as server:
    pathlib.Path(sys.argv[3]).touch()
    server.serve_forever()
PY
  SERVER_PID=$!
  local tries=0
  until [[ -f "$WORK/ready" ]]; do
    kill -0 "$SERVER_PID" 2>/dev/null || fail "Cannot serve payment page; choose a different PAYMENT_PORT ($PAYMENT_PORT is busy?)"
    tries=$((tries + 1)); [[ "$tries" -le 50 ]] || fail 'Payment page startup timed out'
    sleep 0.1
  done
}

payment_page() {
  local role="$1" payment_id="$2" phase="$3"
  start_server
  api "$role" POST "/api/payments/$payment_id/session" "$WORK/session.json" 200
  # A bank session contains temporary credentials: serve only on loopback,
  # never copy it to OUTPUT_DIR, and remove it when this process exits.
  python3 - "$WORK/session.json" "$WORK/web/$phase.html" <<'PY'
import json, pathlib, sys
session = json.loads(pathlib.Path(sys.argv[1]).read_text())
script = 'https://test-epay.epayment.kz/payform/payment-api.js'
if session.get('scriptUrl') != script:
    raise SystemExit('Refusing an unexpected/non-sandbox payment script')
payment = json.dumps(session['paymentObject']).replace('<', '\\u003c')
page = '''<!doctype html><meta charset="utf-8"><title>BiletFlow test payment</title>
<h1>BiletFlow Halyk sandbox</h1><p>Use sandbox card details. Keep the terminal script running.</p>
<button id="pay" disabled>Open Halyk test payment</button><p id="message">Loading bank form…</p>
<script src="''' + script + '''" onload="document.getElementById('pay').disabled=false;document.getElementById('message').textContent='Ready'"
onerror="document.getElementById('message').textContent='Bank script failed to load'"></script>
<script>const payment = ''' + payment + ''';
document.getElementById('pay').onclick = () => { halyk.pay(payment); };</script>'''
pathlib.Path(sys.argv[2]).write_text(page)
PY
  printf '\nOpen http://127.0.0.1:%s/%s.html and complete the Halyk sandbox payment.\n' "$PAYMENT_PORT" "$phase"
  printf 'Waiting for backend confirmation (up to %ss)…\n' "$TIMEOUT_SECONDS"
}

if [[ "$ACTIVATE" = 1 ]]; then
  printf '%s\n' '{"acceptSandboxTerms":true,"simulateIdentityAndPayoutVerification":true}' > "$WORK/activation-request.json"
  api organizer POST "/api/payments/events/$EVENT_ID/activation" "$WORK/activation.json" 200 "$WORK/activation-request.json"
  api organizer GET "/api/payments/events/$EVENT_ID/activation" "$WORK/activation-status.json" 200
  if [[ "$(jq -r '.status' "$WORK/activation-status.json")" != ACTIVE ]]; then
    activation_payment="$(jq -er '.paymentId' "$WORK/activation.json")"
    payment_page organizer "$activation_payment" activation
    deadline=$((SECONDS + TIMEOUT_SECONDS))
    while :; do
      api organizer GET "/api/payments/events/$EVENT_ID/activation" "$WORK/activation-status.json" 200
      [[ "$(jq -r '.status' "$WORK/activation-status.json")" != ACTIVE ]] || break
      [[ "$SECONDS" -lt "$deadline" ]] || fail 'Activation did not become ACTIVE; inspect payment status before retrying'
      sleep 3
    done
    rm -f "$WORK/web/activation.html"
  fi
  printf 'PASS: paid-sales activation is ACTIVE\n'
fi

jq -n --arg event "$EVENT_ID" --arg type "$TICKET_TYPE_ID" --arg email "$ATTENDEE_EMAIL" \
  '{eventId:$event,selections:[{ticketTypeId:$type,seats:[],attendeeEmails:[$email]}]}' > "$WORK/request.json"
printf 'Checkout ID: %s\n' "$CHECKOUT_ID"
api buyer POST /api/checkouts "$WORK/checkout.json" 200 "$WORK/request.json" "$CHECKOUT_ID"
jq -e --arg id "$CHECKOUT_ID" --arg event "$EVENT_ID" \
  '.id == $id and .eventId == $event and (.status == "AWAITING_PAYMENT" or .status == "COMPLETED")' "$WORK/checkout.json" >/dev/null || fail 'Unexpected checkout'
api buyer POST /api/checkouts "$WORK/replay.json" 200 "$WORK/request.json" "$CHECKOUT_ID"
[[ "$(jq -c '[.id,.paymentId,.amountKzt]' "$WORK/checkout.json")" = "$(jq -c '[.id,.paymentId,.amountKzt]' "$WORK/replay.json")" ]] || fail 'Checkout retry changed purchase identity/price'
printf 'PASS: checkout retry reused the same purchase and price\n'

if [[ "$(jq -r '.status' "$WORK/checkout.json")" = AWAITING_PAYMENT ]]; then
  payment_id="$(jq -er '.paymentId' "$WORK/checkout.json")"
  payment_page buyer "$payment_id" checkout
  deadline=$((SECONDS + TIMEOUT_SECONDS))
  while :; do
    api buyer GET "/api/checkouts/$CHECKOUT_ID" "$WORK/checkout.json" 200
    status="$(jq -r '.status' "$WORK/checkout.json")"
    [[ "$status" != COMPLETED ]] || break
    [[ "$status" = AWAITING_PAYMENT ]] || fail "Checkout ended with status $status"
    [[ "$SECONDS" -lt "$deadline" ]] || fail "Checkout timed out. Inspect $CHECKOUT_ID before starting another purchase"
    sleep 3
  done
  rm -f "$WORK/web/checkout.html"
fi
jq -e --arg type "$TICKET_TYPE_ID" --arg email "$ATTENDEE_EMAIL" \
  '.status == "COMPLETED" and (.tickets | length) == 1 and .tickets[0].status == "VALID" and .tickets[0].ticketTypeId == $type and (.tickets[0].attendeeEmail | ascii_downcase) == ($email | ascii_downcase)' \
  "$WORK/checkout.json" >/dev/null || fail 'Expected exactly one valid ticket for the buyer'
ticket_id="$(jq -er '.tickets[0].id' "$WORK/checkout.json")"
api buyer POST /api/checkouts "$WORK/replay.json" 200 "$WORK/request.json" "$CHECKOUT_ID"
[[ "$(jq -c '.tickets | map(.id) | sort' "$WORK/checkout.json")" = "$(jq -c '.tickets | map(.id) | sort' "$WORK/replay.json")" ]] || fail 'Replay issued different tickets'
printf 'PASS: purchase completed and replay returned the same ticket\n'

api buyer POST "/api/tickets/$ticket_id/claim" "$WORK/claim.json" 200,204
api buyer POST "/api/tickets/$ticket_id/claim" "$WORK/claim-replay.json" 200,204
api buyer GET "/api/tickets/$ticket_id/pdf" "$OUTPUT_DIR/ticket-$ticket_id.pdf" 200
api buyer GET "/api/tickets/$ticket_id/qr" "$OUTPUT_DIR/ticket-$ticket_id.png" 200
python3 - "$OUTPUT_DIR/ticket-$ticket_id.pdf" "$OUTPUT_DIR/ticket-$ticket_id.png" <<'PY'
import pathlib, sys
assert pathlib.Path(sys.argv[1]).read_bytes().startswith(b'%PDF-'), 'Invalid PDF response'
assert pathlib.Path(sys.argv[2]).read_bytes().startswith(b'\x89PNG\r\n\x1a\n'), 'Invalid PNG response'
PY
cp "$WORK/checkout.json" "$OUTPUT_DIR/checkout.json"
printf 'PASS: verified-email claim is repeatable; ticket PDF and QR downloaded\n'
printf '\nPurchase passed. Ticket: %s\nFiles: %s\n' "$ticket_id" "$OUTPUT_DIR"
printf 'Automatic email delivery is asynchronous; inspect the attendee inbox (Mailpit in dev).\n'
if [[ "$CANCEL_EVENT" = 1 ]]; then
  printf '\nTesting event cancellation…\n'
  api organizer POST "/api/events/$EVENT_ID/cancel" "$WORK/cancel.json" 204
  api organizer POST "/api/events/$EVENT_ID/cancel" "$WORK/cancel-replay.json" 204
  api buyer GET "/api/events/$EVENT_ID" "$WORK/cancelled-event.json" 200
  jq -e '.status == "CANCELLED"' "$WORK/cancelled-event.json" >/dev/null || fail 'Event is not cancelled'
  api buyer GET "/api/tickets/$ticket_id/qr" "$WORK/rejected-qr.json" 409
  api buyer GET "/api/tickets/$ticket_id/pdf" "$OUTPUT_DIR/ticket-$ticket_id-cancelled.pdf" 200
  rejected_key="$(python3 -c 'import uuid; print(uuid.uuid4())')"
  api buyer POST /api/checkouts "$WORK/rejected-checkout.json" 409 "$WORK/request.json" "$rejected_key"
  ticket_code="$(jq -er '.tickets[0].code' "$WORK/checkout.json")"
  api organizer POST "/api/events/$EVENT_ID/check-in/tickets/$ticket_code" "$WORK/rejected-admission.json" 403
  api buyer GET "/api/checkouts/$CHECKOUT_ID" "$WORK/retained-order.json" 200
  jq -e '.status == "COMPLETED" and .refundId == null' "$WORK/retained-order.json" >/dev/null || fail 'Cancellation altered the completed financial order'
  printf 'PASS: repeated cancellation is safe; sales, QR download, and admission are blocked; completed order retained\n'
  printf 'Waiting for the attendee cancellation notice in Mailpit…\n'
  mail_base="${MAILPIT_URL:-http://localhost:8025}"
  deadline=$((SECONDS + 60))
  while :; do
    mail_status="$(curl --silent --show-error --connect-timeout 5 --max-time 10 --get \
      --data-urlencode "query=to:$ATTENDEE_EMAIL subject:\"BiletFlow event cancelled:\"" \
      --output "$WORK/cancellation-email.txt" --write-out '%{http_code}' "${mail_base%/}/view/latest.txt")" || fail 'Cannot reach Mailpit'
    if [[ "$mail_status" = 200 ]]; then
      cp "$WORK/cancellation-email.txt" "$OUTPUT_DIR/cancellation-email.txt"
      break
    fi
    [[ "$mail_status" = 404 ]] || fail "Mailpit returned HTTP $mail_status"
    [[ "$SECONDS" -lt "$deadline" ]] || fail 'Cancellation email did not arrive within 60s; check outbox, cancellation queue, and SMTP logs'
    sleep 2
  done
  printf 'PASS: attendee cancellation email arrived in Mailpit\n'
else
  printf 'This script does not assert SMTP delivery or admission scanning. Set CANCEL_EVENT=1 to check cancellation and its email.\n'
fi

# ./scripts/e2e/biletflow-run-e2e.sh
#!/usr/bin/env bash
# Create fresh fixtures via public APIs, activate accounts through Mailpit,
# then run biletflow-purchase-e2e.sh from the same directory.
# Requires a running dev backend + Mailpit, curl, jq, Python 3, and Bash.
#   bash biletflow-run-e2e.sh              # Halyk activation + paid purchase
#   PRICE_KZT=0 bash biletflow-run-e2e.sh  # fully automated free purchase
# Options: BASE_URL, MAILPIT_URL, PRICE_KZT (0 or >=10, max 2 decimals),
# MAIL_TIMEOUT_SECONDS=60, E2E_SCRIPT, OUTPUT_DIR, PAYMENT_PORT, TIMEOUT_SECONDS.
# CANCEL_EVENT=1 runs cancellation checks after purchase (also works with PRICE_KZT=0).
# Each run creates two accounts and an UNLISTED published event. Fixtures remain
# for inspection; no SQL, admin seed account, inbox deletion, or auth bypass.
set -euo pipefail
umask 077
fail() { printf 'FAIL: %s\n' "$*" >&2; exit 1; }
for tool in curl jq python3; do command -v "$tool" >/dev/null || fail "Install $tool"; done
ROOT="$(cd -- "$(dirname -- "${BASH_SOURCE[0]}")" && pwd)"
E2E_SCRIPT="${E2E_SCRIPT:-$ROOT/biletflow-purchase-e2e.sh}"
[[ -f "$E2E_SCRIPT" ]] || fail "Put biletflow-purchase-e2e.sh next to this script, or set E2E_SCRIPT to its path"
BASE_URL="${BASE_URL:-http://localhost:8080}"
BASE_URL="${BASE_URL%/}"
MAILPIT_URL="${MAILPIT_URL:-http://localhost:8025}"
MAILPIT_URL="${MAILPIT_URL%/}"
PRICE_KZT="${PRICE_KZT:-1000}"
MAIL_TIMEOUT_SECONDS="${MAIL_TIMEOUT_SECONDS:-60}"
[[ "$MAIL_TIMEOUT_SECONDS" =~ ^[1-9][0-9]*$ ]] || fail 'MAIL_TIMEOUT_SECONDS must be positive'
python3 - "$PRICE_KZT" <<'PY'
from decimal import Decimal
import re, sys
s=sys.argv[1]
if not re.fullmatch(r'\d+(?:\.\d{1,2})?',s): raise SystemExit('PRICE_KZT must be a nonnegative amount with at most 2 decimals')
p=Decimal(s)
if p != 0 and p < 10: raise SystemExit('Paid checkout must be at least 10 KZT')
PY
WORK="$(mktemp -d)"
trap 'rm -rf "$WORK"' EXIT
trap 'exit 130' INT
trap 'exit 143' TERM
RUN_ID="$(python3 -c 'import uuid; print(uuid.uuid4().hex)')"
PASSWORD="$(python3 -c 'import secrets; print(secrets.token_urlsafe(24))')"

# request ROLE METHOD PATH TARGET EXPECTED [BODY_FILE]
# ROLE is public or organizer. JWTs stay in a private temporary header file.
request() {
    local role="$1" method="$2" path="$3" target="$4" expected="$5" code
    local -a args=(--silent --show-error --connect-timeout 10 --max-time 30
        --request "$method" --output "$target" --write-out '%{http_code}')
    if [[ "$role" != public ]]; then args+=(--header "@$WORK/$role.headers"); fi
    if [[ -n "${6:-}" ]]; then args+=(--header 'Content-Type: application/json' --data-binary "@$6"); fi
    code="$(curl "${args[@]}" "$BASE_URL$path")" || fail "Cannot reach $BASE_URL ($method $path)"
    [[ "$code" = "$expected" ]] || {
        printf 'HTTP %s: %s %s\n' "$code" "$method" "$path" >&2
        jq -r '[.title // empty, .detail // empty] | join(": ")' "$target" 2>/dev/null >&2 || true
        fail 'Unexpected API response'
    }
}
request public GET /api/events "$WORK/events.json" 200
code="$(curl --silent --show-error --connect-timeout 5 --max-time 10 --output /dev/null --write-out '%{http_code}' "$MAILPIT_URL/")" || fail 'Start Mailpit (bash dev.sh services)'
[[ "$code" = 200 ]] || fail "Mailpit is unavailable at $MAILPIT_URL (HTTP $code)"

create_account() {
    local role="$1" login="e2e-$1-$RUN_ID" email="e2e-$1-$RUN_ID@example.com"
    jq -n --arg login "$login" --arg email "$email" --arg password "$PASSWORD" \
        '{login:$login,email:$email,password:$password,firstName:"E2E",lastName:"Test",langKey:"en"}' > "$WORK/register.json"
    request public POST /api/register "$WORK/register-response.json" 201 "$WORK/register.json"
    local deadline=$((SECONDS + MAIL_TIMEOUT_SECONDS)) code key
    while :; do
        # Official Mailpit latest-message HTML endpoint, filtered to this unique recipient.
        code="$(curl --silent --show-error --connect-timeout 5 --max-time 10 --get \
            --data-urlencode "query=to:$email" --output "$WORK/activation.html" --write-out '%{http_code}' \
            "$MAILPIT_URL/view/latest.html")" || fail 'Mailpit connection failed'
        case "$code" in
            200) break ;;
            404) ;;
            *) fail "Mailpit returned HTTP $code while waiting for $role activation email" ;;
        esac
        [[ "$SECONDS" -lt "$deadline" ]] || fail "No activation email for $email. Check backend SMTP settings (localhost:1025) and Mailpit"
        sleep 1
    done
    key="$(python3 - "$WORK/activation.html" <<'PY'
from html.parser import HTMLParser
from pathlib import Path
from urllib.parse import urlparse, parse_qs
import sys
class Activation(HTMLParser):
    key=None
    def handle_starttag(self,tag,attrs):
        if tag != 'a': return
        link=dict(attrs).get('href','')
        parsed=urlparse(link)
        if parsed.path.endswith('/account/activate'):
            values=parse_qs(parsed.query).get('key',[])
            if values: self.key=values[0]
p=Activation(); p.feed(Path(sys.argv[1]).read_text())
if not p.key: raise SystemExit('Activation email has no account activation link')
print(p.key)
PY
)"
    # Call only the configured backend, never an arbitrary URL from the email.
    code="$(curl --silent --show-error --connect-timeout 10 --max-time 30 --get \
        --data-urlencode "key=$key" --output "$WORK/activate-response.json" --write-out '%{http_code}' \
        "$BASE_URL/api/activate")" || fail 'Account activation connection failed'
    [[ "$code" = 200 ]] || fail "Account activation returned HTTP $code"
    jq -n --arg user "$login" --arg password "$PASSWORD" \
        '{username:$user,password:$password,rememberMe:false}' > "$WORK/login.json"
    request public POST /api/authenticate "$WORK/login-response.json" 200 "$WORK/login.json"
    local jwt

import tech.jhipster.config.JHipsterProperties;

public class SmtpEmailSender implements EmailSender {

    private final JavaMailSender mail;
    private final JHipsterProperties properties;

    public SmtpEmailSender(JavaMailSender mail, JHipsterProperties properties) {
        this.mail = Objects.requireNonNull(mail);
        this.properties = Objects.requireNonNull(properties);
    }

    @Override
    public void send(Email email) {
        try {
            var mime = mail.createMimeMessage();
            var message = new MimeMessageHelper(mime, true, StandardCharsets.UTF_8.name());
            message.setFrom(properties.getMail().getFrom());
            message.setTo(new InternetAddress(email.recipient(), true));
            message.setSubject(email.subject().replaceAll("[\r\n]+", " "));
            message.setText(email.text(), false);
            message.addAttachment(email.filename(), new ByteArrayResource(email.attachment()), email.attachmentContentType());
            mime.setHeader("Message-ID", "<" + email.id() + "@biletflow.invalid>");
            mail.send(mime);
        } catch (MessagingException failure) {
            throw new MailPreparationException("Email could not be prepared", failure);
        }
    }

import java.time.Instant;
import java.util.Locale;
import java.util.Objects;
import java.util.UUID;

/** Immutable delivery snapshot. The message ID is stable across event redelivery and SMTP retries. */
public record CancellationNotice(
    UUID id,
    UUID eventId,
    String recipient,
    String title,
    Instant startsAt,
    Instant endsAt,
    Instant cancelledAt
) {
    public CancellationNotice {
        Objects.requireNonNull(id);
        Objects.requireNonNull(eventId);
        recipient = Objects.requireNonNull(recipient).trim().toLowerCase(Locale.ROOT);
        Objects.requireNonNull(title);
        Objects.requireNonNull(startsAt);
        Objects.requireNonNull(endsAt);
        Objects.requireNonNull(cancelledAt);
        if (recipient.isBlank()) throw new IllegalArgumentException("Cancellation notice recipient is blank");
    }

    public static CancellationNotice forRecipient(
        UUID eventId,
        String recipient,
        String title,
        Instant startsAt,
        Instant endsAt,
        Instant cancelledAt
    ) {
        String email = recipient.trim().toLowerCase(Locale.ROOT);
        UUID id = UUID.nameUUIDFromBytes(("event-cancellation:" + eventId + ":" + email).getBytes(StandardCharsets.UTF_8));
        return new CancellationNotice(id, eventId, email, title, startsAt, endsAt, cancelledAt);
    }
}

package com.biletflow.biletflow.eventmanagement.application.cancellation;

import java.time.Clock;
import java.util.Objects;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.stereotype.Service;

@Service
public class CancellationNoticeWorker {

    private static final Logger LOG = LoggerFactory.getLogger(CancellationNoticeWorker.class);
    private final CancellationNoticeStore notices;
    private final CancellationNoticeSender sender;
    private final Clock clock;

    public CancellationNoticeWorker(CancellationNoticeStore notices, CancellationNoticeSender sender, Clock clock) {
        this.notices = Objects.requireNonNull(notices);
        this.sender = Objects.requireNonNull(sender);
        this.clock = Objects.requireNonNull(clock);
    }

    public void deliverPending() {
        for (int i = 0; i < 20; i++) {
            var next = notices.claim(clock.instant());
            if (next.isEmpty()) return;
            var claim = next.orElseThrow();
            try {
                sender.send(claim.notice());
                notices.complete(claim, clock.instant());
            } catch (RuntimeException failure) {
                notices.retry(claim, clock.instant());
                LOG.warn("Cancellation notice {} will be retried ({})", claim.notice().id(), failure.getClass().getSimpleName());
            }
        }
    }
}

/** Fan-out and outbox acknowledgement commit together; SMTP delivery is a separate worker. */
@Component
public class CancellationNotices implements IntegrationEventHandler {

    private final SocialEventRepository events;
    private final CancellationRecipients recipients;
    private final CancellationNoticeStore notices;

    public CancellationNotices(SocialEventRepository events, CancellationRecipients recipients, CancellationNoticeStore notices) {
        this.events = Objects.requireNonNull(events);
        this.recipients = Objects.requireNonNull(recipients);
        this.notices = Objects.requireNonNull(notices);
    }

    @Override
    public String eventType() {
        return EventCancelled.TYPE;
    }

    @Override
    @Transactional
    public void handle(IntegrationEvent message) {
        var cancelled = EventCancelled.from(message);
        var event = events
            .findById(new SocialEventId(cancelled.eventId()))
            .orElseThrow(() -> new SocialEventNotFoundException(cancelled.eventId().toString()));
        if (event.getStatus() != SocialEventStatus.CANCELLED) throw new IllegalStateException("Event is not cancelled");
        var emails = new LinkedHashSet<>(recipients.attendees(cancelled.eventId()));
        recipients.verifiedEmail(event.getOrganizerId()).ifPresent(emails::add);
        for (var staff : event.getStaffAssignments()) recipients.verifiedEmail(staff.userId()).ifPresent(emails::add);
        for (String email : emails)
            notices.enqueue(
                CancellationNotice.forRecipient(
                    cancelled.eventId(),
                    email,
                    event.getTitle(),
                    event.getDateRange().startAt(),
                    event.getDateRange().endAt(),
                    cancelled.cancelledAt()
                )
            );
    }

            throw new InvalidEventStateException("Cannot publish a cancelled event");
        }

        if (venue == null) {
            throw new InvalidEventStateException("Cannot publish an event without a venue configured");

        status = SocialEventStatus.PUBLISHED;

        if (status != SocialEventStatus.PUBLISHED) {
            throw new InvalidEventStateException("Only published events can be unpublished");

        status = SocialEventStatus.UNPUBLISHED;

        if (status == SocialEventStatus.CANCELLED) return;
        if (dateRange.hasEnded(now)) {
            throw new InvalidEventStateException("Cannot cancel an event that has already ended");

import com.biletflow.biletflow.common.notifications.EmailSender;
import com.biletflow.biletflow.eventmanagement.application.cancellation.*;
import java.nio.charset.StandardCharsets;
import java.time.ZoneOffset;
import java.time.format.DateTimeFormatter;
import java.util.Objects;
import org.springframework.stereotype.Component;

@Component
public class SmtpCancellationNoticeSender implements CancellationNoticeSender {

    private static final DateTimeFormatter UTC = DateTimeFormatter.ofPattern("uuuuMMdd'T'HHmmss'Z'").withZone(ZoneOffset.UTC);
    private final EmailSender emails;

    public SmtpCancellationNoticeSender(EmailSender emails) {
        this.emails = Objects.requireNonNull(emails);
    }

    @Override
    public void send(CancellationNotice notice) {
        String text =
            "Event cancelled: " +
            notice.title() +
            "\n\n" +
            "This event will not take place. Its tickets cannot be used for admission.\n" +
            "The attached calendar file marks the event as cancelled.\n\n" +
            "This notice does not confirm a refund. Contact the organizer about refund eligibility and status.\n";
        String calendar = String.join(
            "\r\n",
            "BEGIN:VCALENDAR",
            "VERSION:2.0",
            "PRODID:-//BiletFlow//Events//EN",
            "METHOD:PUBLISH",
            "BEGIN:VEVENT",
            "UID:" + notice.eventId() + "@biletflow.invalid",
            "SEQUENCE:1",
            "DTSTAMP:" + UTC.format(notice.cancelledAt()),
            "LAST-MODIFIED:" + UTC.format(notice.cancelledAt()),
            "DTSTART:" + UTC.format(notice.startsAt()),
            "DTEND:" + UTC.format(notice.endsAt()),
            "SUMMARY:" + escape(notice.title()),
            "STATUS:CANCELLED",
            "END:VEVENT",
            "END:VCALENDAR",
            ""
        );
        emails.send(
            new EmailSender.Email(
                notice.id(),
                notice.recipient(),
                "BiletFlow event cancelled: " + notice.title(),
                text,
                "event-" + notice.eventId() + "-cancelled.ics",
                fold(calendar).getBytes(StandardCharsets.UTF_8),
                "text/calendar; charset=UTF-8"
            )
        );
    }

    private static String escape(String value) {
        return value
            .replace("\\", "\\\\")
            .replace("\r\n", "\n")
            .replace("\r", "\n")
            .replace("\n", "\\n")
            .replace(";", "\\;")
            .replace(",", "\\,");
    }

    /** RFC 5545 physical lines are at most 75 UTF-8 octets, including continuation whitespace. */
    private static String fold(String calendar) {
        var out = new StringBuilder();
        for (String line : calendar.split("\r\n", -1)) {
            if (!out.isEmpty()) out.append("\r\n");
            int bytes = 0;
            for (int cp : line.codePoints().toArray()) {
                String c = new String(Character.toChars(cp));
                int size = c.getBytes(StandardCharsets.UTF_8).length;
                if (bytes + size > 75) {
                    out.append("\r\n ");
                    bytes = 1;
                }
                out.append(c);
                bytes += size;
            }
        }
        return out.toString();
    }
}

    public JpaCancellationNoticeStore(EntityManager entities) {
        this.entities = Objects.requireNonNull(entities);
    }

    @Override
    @Transactional(propagation = Propagation.MANDATORY)
    public void enqueue(CancellationNotice notice) {
        if (entities.find(CancellationNoticeJpaEntity.class, notice.id()) == null) {
            entities.persist(new CancellationNoticeJpaEntity(notice));
        }
    }

    @Override
    public Optional<Claim> claim(Instant now) {
        return entities
            .createQuery(
                "select n from CancellationNoticeJpaEntity n where n.sentAt is null and n.nextAttemptAt <= :now " +
                    "and (n.leaseUntil is null or n.leaseUntil <= :now) order by n.nextAttemptAt, n.id",
                CancellationNoticeJpaEntity.class
            )
            .setParameter("now", now)
            .setMaxResults(1)
            .setLockMode(LockModeType.PESSIMISTIC_WRITE)
            .getResultList()
            .stream()
            .findFirst()
            .map(row -> row.claim(now));
    }

    @Override
    public void complete(Claim claim, Instant now) {
        var row = entities.find(CancellationNoticeJpaEntity.class, claim.notice().id(), LockModeType.PESSIMISTIC_WRITE);
        if (row != null) row.complete(claim, now);
    }

    @Override
    public void retry(Claim claim, Instant now) {
        var row = entities.find(CancellationNoticeJpaEntity.class, claim.notice().id(), LockModeType.PESSIMISTIC_WRITE);

package com.biletflow.biletflow.eventmanagement.persistence.cancellation.entity;

import com.biletflow.biletflow.eventmanagement.application.cancellation.CancellationNotice;
import com.biletflow.biletflow.eventmanagement.application.cancellation.CancellationNoticeStore.Claim;
import jakarta.persistence.*;
import java.time.Instant;
import java.util.UUID;

@Entity
@Table(
    name = "event_management_cancellation_notice",
    uniqueConstraints = @UniqueConstraint(name = "uk_event_cancellation_recipient", columnNames = { "event_id", "recipient" })
)
public class CancellationNoticeJpaEntity {

    @Id
    private UUID id;

    @Column(name = "event_id", nullable = false, updatable = false)
    private UUID eventId;

    @Column(nullable = false, updatable = false, length = 254)
    private String recipient;

    @Column(nullable = false, updatable = false, length = 255)
    private String title;

    @Column(name = "starts_at", nullable = false, updatable = false)
    private Instant startsAt;

    @Column(name = "ends_at", nullable = false, updatable = false)
    private Instant endsAt;

    @Column(name = "cancelled_at", nullable = false, updatable = false)
    private Instant cancelledAt;

    @Column(name = "next_attempt_at", nullable = false)
    private Instant nextAttemptAt;

    @Column(nullable = false)
    private int attempts;

    @Column(name = "claim_token")
    private UUID claimToken;

    @Column(name = "lease_until")
    private Instant leaseUntil;

    @Column(name = "sent_at")
    private Instant sentAt;

    @Version
    private long version;

    protected CancellationNoticeJpaEntity() {}

    public CancellationNoticeJpaEntity(CancellationNotice notice) {
        id = notice.id();
        eventId = notice.eventId();
        recipient = notice.recipient();
        title = notice.title();
        startsAt = notice.startsAt();
        endsAt = notice.endsAt();
        cancelledAt = notice.cancelledAt();
        nextAttemptAt = notice.cancelledAt();
    }

    public Claim claim(Instant now) {
        if (sentAt != null || nextAttemptAt.isAfter(now) || (leaseUntil != null && leaseUntil.isAfter(now))) {
            throw new IllegalStateException("Cancellation notice is not available");
        }
        claimToken = UUID.randomUUID();
        leaseUntil = now.plusSeconds(120);
        attempts = Math.min(attempts + 1, 1000000);
        return new Claim(new CancellationNotice(id, eventId, recipient, title, startsAt, endsAt, cancelledAt), claimToken);
    }

    public void complete(Claim claim, Instant now) {
        if (!owns(claim)) return;
        sentAt = now;
        claimToken = null;
        leaseUntil = null;
    }

    public void retry(Claim claim, Instant now) {
        if (!owns(claim)) return;
        nextAttemptAt = now.plusSeconds(Math.min(3600, 30L << Math.min(Math.max(0, attempts - 1), 7)));
        claimToken = null;
        leaseUntil = null;
    }

    private boolean owns(Claim claim) {
        return sentAt == null && claim.token().equals(claimToken);
    }
}

    public CheckoutService(
        CheckoutSessionRepository checkouts,
        OrderRepository orders,
        CheckoutProcessRepository processes,
        CheckoutInventoryOhs inventory,
        PaymentsOhs payments,
        EventManagementOhs events,
        TransactionLocks locks,
        FinancialAudit audit,
        CheckoutFingerprint fingerprints,
        Clock clock
    ) {
        this.checkouts = Objects.requireNonNull(checkouts, "checkouts cannot be null");
        this.orders = Objects.requireNonNull(orders, "orders cannot be null");
        this.processes = Objects.requireNonNull(processes, "processes cannot be null");
        this.inventory = Objects.requireNonNull(inventory, "inventory cannot be null");
        this.payments = Objects.requireNonNull(payments, "payments cannot be null");
        this.events = Objects.requireNonNull(events, "events cannot be null");
        this.locks = Objects.requireNonNull(locks, "locks cannot be null");
        this.audit = Objects.requireNonNull(audit, "audit cannot be null");

        this.clock = Objects.requireNonNull(clock, "clock cannot be null");

    @Transactional
    public CheckoutView create(UUID id, long owner, CreateCheckoutCommand request) {
        if (request.selections().isEmpty() || request.selections().size() > 30) throw new IllegalArgumentException(
            "Supply 1 to 30 ticket selections"
        );
        locks.lock("event-lifecycle:" + request.eventId());
        locks.lock("checkout:" + id);
        String fingerprint = fingerprints.of(request);
        var prior = processes.find(id);
        if (prior.isPresent()) {
            var p = prior.orElseThrow();
            authorizeOwner(p, owner);
            if (!p.fingerprint().equals(fingerprint)) throw new IllegalStateException("Idempotency-Key was used for a different checkout");
            return view(p, requireCheckout(id));
        }
        var scope = events.salesScope(request.eventId(), clock.instant());
        if (!scope.registrationOpen()) throw new IllegalStateException("Event is not accepting registrations");
        var held = inventory.reserve(request.eventId(), id, request.selections());
        var checkout = new CheckoutSession(
            new CheckoutSessionId(id),
            owner,
            request.eventId(),
            held.assignedSeating() ? InventoryMode.RESERVED_SEATING : InventoryMode.GENERAL_ADMISSION
        );
        for (var line : held.lines())
            checkout.addItem(
                line.seatId() == null
                    ? new GeneralAdmissionCheckoutItem(line.ticketTypeId(), line.price())
                    : new AssignedSeatingCheckoutItem(line.ticketTypeId(), line.seatId(), line.price())
            );
        var process = new CheckoutProcess(
            id,
            owner,
            request.eventId(),
            fingerprint,
            held.expiresAt(),
            held.lines(),
            held.holds(),
            null,
            null,
            null
        );
        if (checkout.getFinalPrice().isZero()) {
            inventory.issue(process.eventId(), id, owner, process.lines(), process.holds());
            checkout.completeFreeCheckout();
            orders.save(Order.createFromCheckout(checkout));
            audit.record("ordercheckout", id, owner, "FREE_CHECKOUT_COMPLETED");
        } else {
            checkout.awaitPayment();
            var payment = payments.initiate(
                new StartPaymentCommand(id, process.eventId(), owner, checkout.getFinalPrice().amount(), process.deadline())
            );
            process = process.payment(payment.id());
            audit.record("ordercheckout", id, owner, "PAID_CHECKOUT_AWAITING_PAYMENT");
        }
        checkouts.save(checkout);
        processes.save(process);
        return view(process, checkout);
    }

    public CheckoutView get(UUID id, long actor) {
        var p = requireProcess(id);
        authorizeRead(p, actor);
        return view(p, requireCheckout(id));
    }

    public List<CheckoutView> mine(long actor) {
        return checkouts
            .findAllByOwnerUserId(actor)
            .stream()
            .map(c -> view(requireProcess(c.getId().value()), c))
            .toList();
    }

    @Transactional
    public CheckoutView cancel(UUID id, long actor) {
        locks.lock("checkout:" + id);
        var p = requireProcess(id);
        authorizeOwner(p, actor);
        var c = requireCheckout(id);
        if (
            c.getStatus() == CheckoutSessionStatus.CANCELLED ||
            c.getStatus() == CheckoutSessionStatus.EXPIRED ||
            c.getStatus() == CheckoutSessionStatus.PAYMENT_FAILED
        ) return view(p, c);
        if (c.getStatus() == CheckoutSessionStatus.COMPLETED) throw new IllegalStateException(
            "A completed order requires organizer cancellation or refund"
        );
        c.cancel();
        release(p);
        if (p.paymentId() != null) payments.abandon(p.paymentId());
        checkouts.save(c);
        audit.record("ordercheckout", id, actor, "CHECKOUT_CANCELLED");
        return view(p, c);
    }

    /** MVP policy: only organizers initiate full refunds of unused tickets; no partial refund or automatic customer entitlement. */
    @Transactional
    public CheckoutView refund(UUID id, long organizer, String reason) {
        locks.lock("checkout:" + id);
        var p = requireProcess(id);
        if (!events.canManageTicketing(p.eventId(), organizer)) throw new AuthorizationException(
            "Only the organizer can refund this order"
        );
        var c = requireCheckout(id);
        var existingOrder = orders.findById(new OrderId(id));
        if (existingOrder.isEmpty()) {
            if (p.paymentId() == null || !"SUCCEEDED".equals(payments.get(p.paymentId()).status())) throw new IllegalStateException(
                "No captured payment to refund"
            );
            UUID refund = payments.refund(p.paymentId(), reason);
            p = p.refund(CheckoutRefundStatus.PENDING, refund);
            processes.save(p);
            audit.record("ordercheckout", id, organizer, "UNFULFILLED_ORDER_REFUND_REQUESTED");
            return view(p, c);
        }
        var order = existingOrder.orElseThrow();
        if (p.refundState() == CheckoutRefundStatus.PENDING || p.refundState() == CheckoutRefundStatus.REFUNDED) return view(p, c);
        if (order.getFinalPrice().isZero()) {
            if (order.getStatus() != OrderStatus.CANCELLED) {
                inventory.cancelFreeOrder(p.eventId(), id);
                order.cancelOrderByManager();
                orders.save(order);
            }
            audit.record("ordercheckout", id, organizer, "FREE_ORDER_CANCELLED");
            return view(p, c);
        }
        inventory.prepareRefund(p.eventId(), id);
        UUID refund = payments.refund(p.paymentId(), reason);
        p = p.refund(CheckoutRefundStatus.PENDING, refund);
        processes.save(p);
        audit.record("ordercheckout", id, organizer, "ORDER_REFUND_REQUESTED");
        return view(p, c);
    }

    @Transactional
    public void onOutcome(PaymentOutcome outcome) {
        var initial = requireProcess(outcome.orderId());
        locks.lock("event-lifecycle:" + initial.eventId());
        locks.lock("checkout:" + outcome.orderId());
        var p = requireProcess(outcome.orderId());
        var c = requireCheckout(p.id());
        if (!Objects.equals(p.paymentId(), outcome.paymentId())) throw new IllegalStateException(
            "Payment outcome belongs to a different checkout"
        );
        switch (outcome.outcome()) {
            case "SUCCEEDED" -> {
                var financial = payments.get(outcome.paymentId());
                if ("REFUNDED".equals(financial.status())) {
                    onOutcome(new PaymentOutcome(outcome.paymentId(), outcome.orderId(), "REFUNDED", financial.refundId()));
                    return;
                }
                if (financial.reviewRequired()) throw new IllegalStateException("Payment settlement requires review before fulfillment");
                if ("REQUESTED".equals(financial.refundStatus()) && c.getStatus() == CheckoutSessionStatus.AWAITING_PAYMENT) {
                    c.cancel();
                    release(p);
                    checkouts.save(c);
                    processes.save(p.refund(CheckoutRefundStatus.PENDING, financial.refundId()));
                    return;
                }
                if (c.getStatus() == CheckoutSessionStatus.COMPLETED || p.refundState() == CheckoutRefundStatus.REFUNDED) return;
                if (
                    c.getStatus() != CheckoutSessionStatus.AWAITING_PAYMENT ||
                    !clock.instant().isBefore(p.deadline()) ||
                    !events.salesScope(p.eventId(), clock.instant()).registrationOpen()
                ) {
                    if (c.getStatus() == CheckoutSessionStatus.AWAITING_PAYMENT) {
                        c.expire();
                        checkouts.save(c);
                        release(p);
                    }
                    UUID refund = payments.refund(p.paymentId(), "Payment settled after checkout became unavailable");
                    processes.save(p.refund(CheckoutRefundStatus.PENDING, refund));
                    audit.record("ordercheckout", p.id(), null, "UNFULFILLED_PAYMENT_COMPENSATING");
                    return;
                }
                // Failures roll back event handling and are retried by the durable bus. They cannot lose a paid purchase.
                inventory.issue(p.eventId(), p.id(), p.ownerId(), p.lines(), p.holds());
                c.confirmPayment(outcome.paymentId());
                if (orders.findById(new OrderId(p.id())).isEmpty()) orders.save(Order.createFromCheckout(c));
                checkouts.save(c);
                audit.record("ordercheckout", p.id(), null, "PAID_ORDER_COMPLETED");
            }
            case "FAILED" -> {
                if (c.getStatus() == CheckoutSessionStatus.AWAITING_PAYMENT) {
                    c.markPaymentFailed();
                    checkouts.save(c);
                    release(p);
                    audit.record("ordercheckout", p.id(), null, "CHECKOUT_PAYMENT_FAILED");
                }
            }
            case "REFUNDED" -> {
                if (p.refundState() == CheckoutRefundStatus.REFUNDED) return;
                inventory.completeRefund(p.eventId(), p.id());
                var order = orders.findById(new OrderId(p.id()));
                if (order.isPresent()) {
                    var o = order.orElseThrow();
                    if (o.getStatus() == OrderStatus.COMPLETED) o.cancelOrderByManager();
                    o.markRefunded(outcome.refundId());
                    orders.save(o);
                } else if (c.getStatus() == CheckoutSessionStatus.AWAITING_PAYMENT) {
                    c.cancel();
                    release(p);
                    checkouts.save(c);
                }
                processes.save(p.refund(CheckoutRefundStatus.REFUNDED, outcome.refundId()));
                audit.record("ordercheckout", p.id(), null, "ORDER_REFUND_COMPLETED");
            }
            case "REFUND_FAILED" -> {
                if (p.refundState() != CheckoutRefundStatus.REFUNDED && Objects.equals(p.refundId(), outcome.refundId())) {
                    inventory.failRefund(p.eventId(), p.id());
                    processes.save(p.refund(CheckoutRefundStatus.FAILED, outcome.refundId()));
                    audit.record("ordercheckout", p.id(), null, "ORDER_REFUND_FAILED");
                }
            }
            default -> throw new IllegalArgumentException("Unknown payment outcome");
        }
    }

    @Transactional
    public void expire(UUID id) {
        locks.lock("checkout:" + id);
        var p = requireProcess(id);
        var c = requireCheckout(id);
        if (c.getStatus() != CheckoutSessionStatus.AWAITING_PAYMENT && c.getStatus() != CheckoutSessionStatus.IN_PROGRESS) return;
        var scope = events.salesScope(p.eventId(), clock.instant());
        if (clock.instant().isBefore(p.deadline()) && scope.registrationOpen()) return;
        if (scope.cancelled()) c.cancel();
        else c.expire();
        release(p);
        if (p.paymentId() != null) payments.abandon(p.paymentId());
        checkouts.save(c);
        audit.record("ordercheckout", id, null, "CHECKOUT_EXPIRED_OR_EVENT_CLOSED");
    }

    private void release(CheckoutProcess p) {
        inventory.release(p.eventId(), p.id(), p.holds());
    }

    private CheckoutProcess requireProcess(UUID id) {
        return processes.find(id).orElseThrow(() -> new EntityNotFoundException("Checkout not found"));
    }

    private CheckoutSession requireCheckout(UUID id) {
        return checkouts.findById(new CheckoutSessionId(id)).orElseThrow();
    }

    private void authorizeOwner(CheckoutProcess p, long user) {
        if (p.ownerId() != user) throw new AuthorizationException("Checkout is private");
    }

    private void authorizeRead(CheckoutProcess p, long user) {
        if (p.ownerId() != user && !events.canManageTicketing(p.eventId(), user)) throw new AuthorizationException("Checkout is private");
    }

    private CheckoutView view(CheckoutProcess p, CheckoutSession c) {

        );

    @Transactional

    @Transactional
    public void refund(RefundTicketCommand command) {
        Objects.requireNonNull(command, "command cannot be null");

        Ticket ticket = requireTicketForUpdate(command.ticketId());

        boolean changed = ticket.markRefunded();
        if (!changed) {
            return;
        }

        EventInventory inventory = requireInventory(ticket.getEventId());

        if (ticket.getSeatId() == null) {
            inventory.reverseGASale(ticket.getTicketTypeId(), 1);
        } else {
            inventory.refundSoldSeat(ticket.getSeatId(), ticket.getOrderId());
        }

        ticketRepository.save(ticket);
        inventoryRepository.save(inventory);
    }

    @Transactional
    public TicketView checkIn(CheckInTicketCommand command) {
        Objects.requireNonNull(command, "command cannot be null");
        locks.lock("event-lifecycle:" + command.expectedEventId());
        if (events.ticketDetails(command.expectedEventId(), null).cancelled()) {
            throw new IllegalStateException("Event is cancelled");
        }

        Ticket ticket = requireTicketByCodeForUpdate(command.ticketCode());

        ensureExpectedEvent(ticket, command.expectedEventId());

        ticket.checkIn();

        return toView(ticketRepository.save(ticket));
    }

    @Transactional
    public TicketView reverseCheckIn(ReverseCheckInCommand command) {
        Objects.requireNonNull(command, "command cannot be null");
        locks.lock("event-lifecycle:" + command.expectedEventId());
        if (events.ticketDetails(command.expectedEventId(), null).cancelled()) {
            throw new IllegalStateException("Event is cancelled");
        }

        Ticket ticket = requireTicketByCodeForUpdate(command.ticketCode());

        ensureExpectedEvent(ticket, command.expectedEventId());

        ticket.reverseCheckIn();

        return toView(ticketRepository.save(ticket));
    }

    @Transactional
    public TicketView claim(ClaimTicketCommand command) {
        Objects.requireNonNull(command, "command cannot be null");

        Long userId = currentActor.requireUserId();
        Ticket ticket = requireTicketForUpdate(command.ticketId());

        String verifiedEmail = verifiedUserEmailPort
            .findVerifiedEmail(userId)
            .orElseThrow(() -> new AuthorizationException("Authenticated user does not have a verified email"));

        AttendeeEmail normalizedVerifiedEmail = new AttendeeEmail(verifiedEmail);

        if (!ticket.getAttendeeEmail().equals(normalizedVerifiedEmail)) {
            throw new AuthorizationException("Ticket attendee email does not match the authenticated user");
        }

        ticket.linkOwner(userId);

        return toView(ticketRepository.save(ticket));
    }

    public List<TicketView> getMine() {
        Long userId = currentActor.requireUserId();

        return ticketRepository.findAllByOwnerUserId(userId).stream().map(this::toView).toList();
    }

    public TicketView get(UUID ticketId) {
        return toView(requireTicket(ticketId));
    }

    public List<TicketView> getByOrder(UUID orderId) {
        Objects.requireNonNull(orderId, "orderId cannot be null");

        return ticketRepository.findAllByOrderId(new OrderId(orderId)).stream().map(this::toView).toList();
    }

    public List<TicketView> getByOwnerUserId(Long userId) {
        Objects.requireNonNull(userId, "userId cannot be null");

        return ticketRepository.findAllByOwnerUserId(userId).stream().map(this::toView).toList();
    }

    public TicketValidationResult validate(UUID ticketCode, UUID expectedEventId) {
        Ticket ticket = requireTicketByCode(ticketCode);

        ensureExpectedEvent(ticket, expectedEventId);

        return new TicketValidationResult(
            ticket.getId().value(),
            ticket.getEventId(),
            ticket.getTicketTypeId().value(),
            ticket.getSeatId() == null ? null : ticket.getSeatId().value(),
            ticket.getStatus(),
            ticket.getStatus() == TicketStatus.VALID && !events.ticketDetails(ticket.getEventId(), null).cancelled()
        );
    }

    private Ticket requireTicketForUpdate(UUID ticketId) {
        Ticket ticket = requireTicket(ticketId);
        return requireTicketByCodeForUpdate(ticket.getTicketCode().value());
    }

    private Ticket requireTicket(UUID ticketId) {
        Objects.requireNonNull(ticketId, "ticketId cannot be null");

        return ticketRepository
            .findById(new TicketId(ticketId))
            .orElseThrow(() -> new EntityNotFoundException("Ticket not found: " + ticketId));
    }

    private Ticket requireTicketByCode(UUID rawTicketCode) {
        Objects.requireNonNull(rawTicketCode, "ticketCode cannot be null");

        TicketCode ticketCode = new TicketCode(rawTicketCode);

        return ticketRepository
            .findByTicketCode(ticketCode)
            .orElseThrow(() -> new EntityNotFoundException("Ticket not found for supplied ticket code"));
    }

    private Ticket requireTicketByCodeForUpdate(UUID rawTicketCode) {
        Objects.requireNonNull(rawTicketCode, "ticketCode cannot be null");
        return ticketRepository
            .findByTicketCodeForUpdate(new TicketCode(rawTicketCode))
            .orElseThrow(() -> new EntityNotFoundException("Ticket not found for supplied ticket code"));
    }

    private EventInventory requireInventory(UUID eventId) {
        return inventoryRepository
            .findByEventId(eventId)
            .orElseThrow(() -> new EntityNotFoundException("EventInventory not found for event: " + eventId));
    }

    private void ensureExpectedEvent(Ticket ticket, UUID expectedEventId) {
        if (!ticket.getEventId().equals(expectedEventId)) {
            throw new IllegalStateException("Ticket is not valid for the selected event");
        }
    }

    private TicketView toView(Ticket ticket) {
        return new TicketView(
            ticket.getId().value(),
            ticket.getTicketTypeId().value(),
            ticket.getEventId(),
            ticket.getOrderId().value(),
            ticket.getAttendeeEmail().value(),
            ticket.getOwnerUserId(),
            ticket.getSeatId() == null ? null : ticket.getSeatId().value(),
            ticket.getTicketCode().value(),

import java.time.Instant;
import java.util.Objects;
import java.util.UUID;

public class Ticket {

    private final TicketId id;
    private final TicketTypeId ticketTypeId;
    private final UUID eventId;
    private final OrderId orderId;
    private final AttendeeEmail attendeeEmail;
    private final SeatId seatId; // null for GA
    private final TicketCode ticketCode;
    private final Instant issuedAt;

    private Long ownerUserId;
    private TicketStatus status;

    public Ticket(
        TicketId id,
        TicketTypeId ticketTypeId,
        UUID eventId,
        OrderId orderId,
        AttendeeEmail attendeeEmail,
        Long ownerUserId,
        SeatId seatId,
        TicketCode ticketCode,
        TicketStatus status,
        Instant issuedAt
    ) {
        this.id = Objects.requireNonNull(id, "TicketId cannot be null");
        this.ticketTypeId = Objects.requireNonNull(ticketTypeId, "TicketTypeId cannot be null");
        this.eventId = Objects.requireNonNull(eventId, "eventId cannot be null");
        this.orderId = Objects.requireNonNull(orderId, "OrderId cannot be null");
        this.attendeeEmail = Objects.requireNonNull(attendeeEmail, "AttendeeEmail cannot be null");
        this.ownerUserId = ownerUserId;
        this.seatId = seatId;
        this.ticketCode = Objects.requireNonNull(ticketCode, "TicketCode cannot be null");
        this.status = Objects.requireNonNull(status, "Status cannot be null");
        this.issuedAt = Objects.requireNonNull(issuedAt, "issuedAt cannot be null");
    }

    public static Ticket issue(
        TicketTypeId ticketTypeId,
        UUID eventId,
        OrderId orderId,
        AttendeeEmail attendeeEmail,
        Long ownerUserId,
        SeatId seatId,
        Instant now
    ) {
        return new Ticket(
            TicketId.generate(),
            ticketTypeId,
            eventId,
            orderId,
            attendeeEmail,
            ownerUserId,
            seatId,
            TicketCode.generate(),
            TicketStatus.VALID,
            now
        );
    }

    /**
     * Application layer may call this only after Identity confirms that the
     * verified user's email matches attendeeEmail.
     *
     * Same-user retries are idempotent; reassignment to another account fails.
     */
    public void linkOwner(Long userId) {
        Objects.requireNonNull(userId, "UserId cannot be null");

        if (ownerUserId == null) {
            ownerUserId = userId;
            return;
        }

        if (!ownerUserId.equals(userId)) {
            throw new IllegalStateException("Ticket is already linked to another user");
        }
    }

    public void checkIn() {
        if (status != TicketStatus.VALID) {
            throw new IllegalStateException("Only VALID tickets can be checked in; current status: " + status);
        }

        status = TicketStatus.CHECKED_IN;
    }

    public void reverseCheckIn() {
        if (status != TicketStatus.CHECKED_IN) {
            throw new IllegalStateException("Only CHECKED_IN tickets can have check-in reversed");
        }

        status = TicketStatus.VALID;
    }

    /**
     * @return true only when VALID -> CANCELLED occurs.
     *         Same-state retries return false.
     */
    public boolean cancel() {
        if (status == TicketStatus.CANCELLED) {
            return false;
        }

        if (status != TicketStatus.VALID) {
            throw new IllegalStateException("Cannot cancel ticket with status: " + status);
        }

        status = TicketStatus.CANCELLED;
        return true;
    }

    /**
     * @return true only when VALID -> REFUNDED occurs.
     *         Same-state retries return false.
     */
    public boolean markRefunded() {
        if (status == TicketStatus.REFUNDED) {
            return false;
        }

        if (status != TicketStatus.VALID) {
            throw new IllegalStateException("Cannot refund ticket with status: " + status);
        }

        status = TicketStatus.REFUNDED;
        return true;
    }

    /** Locks admission while the bank refund is unresolved; inventory remains sold until confirmation. */
    public void prepareRefund() {
        if (status == TicketStatus.REFUND_PENDING || status == TicketStatus.REFUNDED) return;
        if (status != TicketStatus.VALID) throw new IllegalStateException("Only unused tickets can be refunded");
        status = TicketStatus.REFUND_PENDING;
    }

    public void restoreAfterFailedRefund() {
        if (status == TicketStatus.REFUND_PENDING) status = TicketStatus.VALID;
    }

    /** A verified bank refund must invalidate admission even if it was performed outside this application. */
    public boolean applyConfirmedRefund() {
        if (status == TicketStatus.REFUNDED) return false;
        if (status == TicketStatus.CANCELLED) {
            status = TicketStatus.REFUNDED;
            return false; // Cancellation already released this allocation; a refund must not release it again.
        }
        status = TicketStatus.REFUNDED;
        return true;
    }

    public TicketId getId() {
        return id;
    }

    public TicketTypeId getTicketTypeId() {
        return ticketTypeId;
    }

    public UUID getEventId() {
        return eventId;
    }

    public OrderId getOrderId() {
        return orderId;
    }

    public AttendeeEmail getAttendeeEmail() {
        return attendeeEmail;
    }

    public Long getOwnerUserId() {
        return ownerUserId;
    }

    public SeatId getSeatId() {
        return seatId;
    }

    public TicketCode getTicketCode() {
        return ticketCode;
    }

    /** Current ticket holders and admitted attendees need event cancellation updates. */
    public boolean receivesEventCancellationNotice() {
        return status == TicketStatus.VALID || status == TicketStatus.CHECKED_IN || status == TicketStatus.REFUND_PENDING;
    }

    public TicketStatus getStatus() {
        return status;
    }

    }
